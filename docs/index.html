The rubric

27 checks across seven layers

Each check says why it matters, what the scanner looks for, what earns full and partial credit, and how to fix it. Checks that can't apply, like sandboxing in an agent that never runs commands, are left out of the score instead of counted against you.

L1Tool boundaries

Tools are allowlisted, tiered by risk, sandboxed when they execute, confined to a workspace, and pinned.

TB-01TB-02TB-03TB-04TB-05

L2Human approval gates

Risky actions wait for a person, the approval is bound to that exact action, and anything unexpected fails closed.

AG-01AG-02AG-03AG-04

L3Audit trail

Every tool call is a structured event, traced end to end, stored where it can't be quietly edited, with secrets redacted.

AU-01AU-02AU-03AU-04

L4Secrets and egress

No keys in the repo, secrets loaded at runtime, scanning in CI, and outbound calls limited to known hosts.

SE-01SE-02SE-03SE-04

L5Budgets and limits

Hard caps on steps, spend and time, so a loop or a bad prompt can't run all night on your card.

BL-01BL-02BL-03

L6Untrusted input

Fetched content is labelled as data, model output is schema-validated, and tool arguments are checked before use.

UI-01UI-02UI-03

L7Evals and rollback

Tests run in CI, behaviour evals and safety tests exist, and there is a kill switch or dry-run mode.

ER-01ER-02ER-03ER-04

Orange IDs are critical controls. Missing any one caps the grade at C, whatever the rest looks like.

Scoring

Built so one strong layer can't hide a missing one

The number is a summary. The useful output is the list of gaps, each tied to the line of code it came from.

PASS 2 · PARTIAL 1 · MISSING 0

Weighted by severity: critical ×3, high ×2, medium ×1. Not-applicable checks drop out.

Layers average evenly

A perfect audit trail doesn't make up for having no approval gate, so each layer counts the same.

Critical gaps cap the grade

A 90 with no step cap is still a C. Grades run A at 85 and up to F under 40.

Comments don't count

"We fail closed" in a docstring is not a control. Tests, examples and dev tooling are kept out of production signals.
